# bin

## Purpose
Pre-built Windows DLLs (32-bit and 64-bit) for JBIG and JBIG2 image decoding, used by `jbigdec.py` and `jbig2dec.py` via ctypes when running on Windows.

## Key Files

| File | Description |
|------|-------------|
| `libjbigdec-w32.dll` | JBIG decoder, 32-bit Windows |
| `libjbigdec-w64.dll` | JBIG decoder, 64-bit Windows |
| `libjbig2codec-w32.dll` | JBIG2 decoder (libpoppler/libjbig2dec based), 32-bit Windows |
| `libjbig2codec-w64.dll` | JBIG2 decoder (libpoppler/libjbig2dec based), 64-bit Windows |

## For AI Agents

### Working In This Directory
- These are pre-compiled binary blobs — do not modify
- On Linux/macOS, equivalent `.so` files are compiled from source and placed directly in `lib/` (parent directory)
